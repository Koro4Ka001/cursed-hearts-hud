# Cursed Hearts HUD

OBR Extension для управления персонажами в кампании Cursed Hearts.

## Функционал

### Для игроков:
- Просмотр и управление своим профилем
- HP, Mana, Resource отображение с полосками
- Использование заклинаний (с автоматической тратой маны)
- Управление кошельком (золото/серебро/медь)
- Долгий отдых (восстанавливает HP и Mana, НЕ ресурс)

### Для ГМ:
- Просмотр выделенных токенов
- Нанесение урона с выбором типа
- Редактирование брони персонажей
- Автоматическое обновление HP bar на карте

## Типы урона

### Физические (поглощаются физической бронёй):
- Режущий, Колющий, Дробящий, Рубящий

### Магические (поглощаются магической бронёй):
- Огонь, Лёд, Молния, Свет, Тьма
- Природа, Аркана, Некромантия, Кровь, Хаос
- Порядок, Псионика, Яд, Звук, Сила

### Особый:
- **Чистый** — игнорирует любую броню и сопротивления

## Установка

### 1. Деплой на Vercel

1. Загрузите проект на GitHub
2. Подключите репозиторий к Vercel
3. Деплой произойдёт автоматически

### 2. Google Apps Script

1. Создайте Google Таблицу с листами "Профили" и "Монстры"
2. Настройте колонки согласно структуре ниже
3. Откройте Apps Script (Расширения > Apps Script)
4. Вставьте код из `google-apps-script/Code.gs`
5. Замените `SPREADSHEET_ID` на ID вашей таблицы
6. Опубликуйте как Web App (Развертывание > Новое развертывание)
7. Скопируйте URL и вставьте в `src/api/config.ts`

### 3. Подключение к Owlbear Rodeo

1. Откройте Owlbear Rodeo
2. Перейдите в настройки расширений
3. Добавьте custom extension с URL вашего деплоя

## Структура таблицы "Профили"

| Колонка | Описание |
|---------|----------|
| ID | Уникальный идентификатор |
| Имя | Имя персонажа |
| TokenID | ID токена в OBR |
| HP | Текущее здоровье |
| MaxHP | Максимальное здоровье |
| TempHP | Временные HP |
| Мана | Текущая мана |
| MaxМана | Максимальная мана |
| ИмяРесурса | Название ресурса (Ярость, Ки и т.д.) |
| Ресурс | Текущий ресурс |
| MaxРесурс | Максимальный ресурс |
| ФизБроня | Физическая броня |
| МагБроня | Магическая броня |
| Сопротивления | Формат: "fire:50;ice:-25" (50% к огню, уязвимость 25% к льду) |
| Заклинания | Формат: "Огненный шар:10:Наносит урон;Лечение:5:Восстанавливает HP" |
| Золото | Золотые монеты |
| Серебро | Серебряные монеты |
| Медь | Медные монеты |

## HP Bar Integration

Расширение интегрируется с HP Tracker от bitperfect-software:
- Автоматически обновляет HP bar на карте
- Максимальная ширина бара: 146px
- Поддерживает временные HP

## Ресурс

⚠️ **Важно:** Ресурс НЕ восстанавливается долгим отдыхом!

Кнопки управления:
- **-1** — потратить 1
- **-3** — потратить 3
- **-X** — своё число
- **Max** — восстановить полностью
